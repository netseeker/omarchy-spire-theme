# Spire v1.1.0

Spire now extends its visual identity beyond the desktop with a custom
boot-unlock illustration and matching warm Yaru icons.

## Highlights

- Added custom Plymouth/LUKS boot-unlock artwork
- Added Omarchy unlock preview for **Style → Unlock**
- Added `Yaru-wartybrown` icon theme to better match Spire's bronze palette
- Updated documentation for boot-unlock and icon integration

## Compatibility

Requires Omarchy 4.0+ / Quattro.
