# Spire v1.0.2

Initial public release of Spire for Omarchy 4 / Quattro.

## Highlights

- Complete dark semantic palette built around ink black, parchment, bronze, ember, and smoke-blue tones
- Native Omarchy integration through `colors.toml`
- Minimal `shell.lock.toml` override for a consistent lock-screen password field
- Restrained bronze active-window and shell borders
- Readable muted/comment colors for terminal and editor use
- Six original 16:9 wallpapers at 2560×1440, including four quieter core backgrounds and two character-focused bonus backgrounds
- Consistent Spire emblem across the wallpaper set
- Real Omarchy desktop preview
- Discreet link to the daily editorial-fantasy project behind the visual world
- No scripts, hooks, custom widgets, compositor code, or executable theme extras

## Tested areas

The palette was reviewed in Omarchy's theme preview and exercised across the terminal, Neovim, menus, shell popups, notifications, and lock screen.

## Compatibility

Requires Omarchy 4.0+ / Quattro.
